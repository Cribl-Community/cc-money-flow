# Security policy

Report a vulnerability in Money Flow privately, using GitHub's private vulnerability reporting: on this repository's **Security** tab, choose **Report a vulnerability**. Please do not open a public issue for it.

Say which package you run (`money-flow-<version>.tgz` or `money-flow-<version>-backend.tgz`), which version, and the steps that show the problem. Leave out workspace names, hostnames and data.

Supported versions: the latest release.
